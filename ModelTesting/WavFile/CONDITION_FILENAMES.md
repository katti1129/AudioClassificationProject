# 評価用WAVの条件タグ

`AllAudioClassficationTest_windowed.py` は、ファイル名のタグを
Summary・WindowResults・ConditionMean（ExcelおよびCSV）へ出力します。
タグは `_` で区切ります。順序・大文字小文字は自由で、省略項目は空欄です。
従来の `ambulance_CPA20m_V060_R080.wav` も使用できます。

例：

```text
ambulance_CPA20m_V060_PV-4_R080_OBS1_N24_SEED1_DIF1_REF1_OREF1_SA0_PA0_SPL136.wav
```

| タグ例 | 意味 |
|---|---|
| CPA20m | 最接近距離20 m（初期距離ではない） |
| V060 | 救急車の初期速度60 km/h |
| PV-4 | 歩行者の初期速度-4 km/h |
| R080 | 地面等、比較対象の圧力反射係数0.80 |
| OBS1 | 障害物あり。0ならなし |
| N24 | 実際の障害物数24個 |
| SEED1 | ランダム生成のシード1 |
| DIF1 | 回折有効。0なら無効 |
| REF1 | 反射有効。0なら無効 |
| OREF1 | 障害物面反射の設定が有効。REF0なら実際には反射しない |
| SA-1 | 救急車のx方向加速度-1 m/s² |
| PA0 | 歩行者のx方向加速度0 m/s² |
| SPL136 | 基準距離における設定音圧レベル136 dB |
| SNR-5 | 別途混合した背景雑音に対するSNR -5 dB |

V・PVの符号は、同じ走行軸での方向比較に使います。任意の3次元運動や
複数面の反射係数、障害物の詳細配置はこれらのタグだけでは表現できません。
元のMAT・設定・メタデータも保存してください。SNRタグは雑音を自動混合しません。

ConditionMeanは実験フォルダ名と全タグの値の組み合わせで集計します。
シードも分けて残すため、複数シードをまとめた発表用の平均は別途計算してください。
未記載の条件は推定しません。異なる実験を混ぜないよう、比較に関係するタグを
各ファイルに記載し、元音源の識別名も残してください。

統合シミュレーションが出力する `SIM_<ID>_final.wav` には条件タグがありません。
評価用コピーに上記の名前を付けてください。この変更はMATLABの自動命名や
既存ファイルの改名を行いません。CPAは実際の軌跡から確認してください。
