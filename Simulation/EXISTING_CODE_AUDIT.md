# 既存 MATLAB コード監査（Phase 1–2）

## 監査範囲と結論

`Simulation` 配下に存在した 19 本の `.m` ファイルをすべて確認した。既存コードは、固定音源の直達音から始まり、鏡像法による地面・壁の一次反射、等速／加速移動音源のドップラー、物理音圧への対応付け、フレネルゾーンによる障害物候補抽出、単一ナイフエッジ回折へ段階的に発展している。

完成版では、これらを破棄せず、次を直接の流用元とする。

- 距離と伝搬遅延、`1/r` 振幅減衰: `Direct/` と `Doppler/`
- 実 WAV の遅延時刻補間: `Doppler/realaudio_direct.m`
- 放射時刻の反復解法: `Doppler/accelerated_*.m`
- 鏡像法と反射点: `Direct_GReflection/`
- 複数反射経路の成分合成: `Direct_GReflection_WReflection/`
- 再現可能な障害物生成と第1フレネル判定: `fresnel/fresnel.m`
- ナイフエッジ回折損失: `Diffraction/single_obstacle_diffraction_sin.m`
- RMS 基準の物理音圧校正: `Doppler/norm_realaudio_direct_Greflction.m`

既存スクリプトは比較・追跡用に残し、統合版は関数化した新しい入口からこれらの考え方を呼び出す。

## 現在実装済みの機能

- 実 WAV 読み込み、モノラル化、一部スクリプトで16 kHz化
- Source静止／移動、Receiver静止の軌跡
- 固定端点および移動音源の直接経路
- `1/r` による自由音場の振幅減衰
- 実音声に対する時間軸補間型ドップラー
- 加速音源についての反復放射時刻推定
- 無限平面の鏡像法による地面・壁の一次反射
- seed固定のランダム直方体障害物生成
- 第1フレネルゾーンを使った候補抽出の試作
- 2D単一障害物の見通し遮蔽判定
- 単一周波数のナイフエッジ回折損失
- WAV、Excel、PNG/FIG の個別保存

## 未実装の機能

- Receiver移動、およびSource/Receiver両方の移動
- 全経路で統一された放射時刻方程式とドップラー
- 任意3D線分と直方体障害物の交差判定
- 動く両端に対する時変Fresnel候補判定
- 実音声の複数周波数成分へ適用する周波数依存回折
- 反射点・回折点・候補判定を含む一貫した結果構造
- 各成分の分離保存と、物理振幅を復元できるWAV尺度管理
- Simulation IDを用いたWAV・Excel・図の対応付け
- 一元設定、検証スイート、README、再現可能な一括実行

## 修正が必要な機能

- 観測時刻の音源位置から遅延を引く近似を、放射時刻での音源位置を使う反復解法へ統一する。
- Receiver速度を遅延写像に含める。
- ピーク正規化で物理差を失う保存処理を廃止し、RMS校正したPa信号と共通のPa/full-scale尺度を保存する。
- 反射を固定座標専用コードから、設定可能な静止平面と移動端点に一般化する。
- 障害物中心と幅だけのFresnel判定を、3D直方体の外接球を用いた保守的候補判定へ改善する。
- 高さ比較による遮蔽を、3D線分対AABBのslab交差判定へ置換する。
- 単一周波数回折を、STFT各周波数ビンで損失を適用する時変ナイフエッジ近似へ拡張する。
- 相対パスと手動ファイル名変更を、設定構造体・絶対化された出力先・Simulation IDへ置換する。

## 既存コードを残す理由

既存ディレクトリは、各物理現象を単独で理解するための段階的プロトタイプとして価値がある。このため完成版への置換や削除は行わず、新しい統合関数の理論的・実装的な出発点として対応関係をREADMEに残す。
